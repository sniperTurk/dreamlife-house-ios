# DreamLife House v2.53.0 — build 73

## Parent recovery preview: exact-copy comparison

- Parent recovery previews now explain which **present** save slots have **identical raw bytes**, even when a copy cannot be decoded. This helps distinguish a duplicate backup/pending journal from genuinely different candidates that have the same visible coin and task totals.
- Every present slot displays either `Exact bytes match <copy>` or `No other copy has identical bytes`. Absent slots never count as duplicates and do not show a comparison label. The comparison is included in the combined VoiceOver row alongside the slot name and summary.
- Parent guidance clarifies that identical bytes only indicate duplicate contents, and **different bytes cannot establish which copy is correct**. No copy is automatically selected, merged, restored, deleted or uploaded.
- Inspection token validation and exact-byte rechecks from v2.52 remain in place. Comparison is derived only from the same captured inspection bytes; no independent read is made for the new labels.
- Added a DEBUG-only UI fixture with matching backup and pending bytes; four XCTest source methods, one XCUITest source method and a new executable Swift model smoke suite.
- All character names, game content and assets remain original and unrelated to third-party franchises.
