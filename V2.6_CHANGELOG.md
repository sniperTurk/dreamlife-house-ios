# DreamLife House v2.6

- Friendship Keepsakes can now be displayed in any house room after they are earned.
- A keepsake can appear in only one room at a time; moving it automatically removes the previous placement.
- Keepsake display placement is persisted in save data and sanitized during load.
- Friends collection UI now includes room-placement controls for each owned keepsake.
- Added three regression tests covering ownership gating, single-room placement, and persistence.
