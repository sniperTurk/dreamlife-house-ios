# DreamLife House 2.9.0

- Added **Memory Spotlight**, a rotating daily objective that selects one owned Friendship Keepsake based on the in-game day.
- Visiting the spotlight keepsake unlocks a one-time +20 coin bonus; interacting with other keepsakes does not satisfy the objective.
- Spotlight claim state resets naturally on the next in-game day and complements Daily Memory Spark without replacing it.
- House UI now identifies today’s spotlight keepsake and its visit/claim state.
- Added regression coverage for daily rotation, target-specific qualification, one-time rewards, and next-day reset behavior.
