# DreamLife House v2.38.0 — build 58

## Crash/interruption-safe save staging
- Added a `save.pending` journal record. Each write encodes the complete snapshot and stages it before rotating a valid primary into backup and writing the new primary.
- On startup, a valid staged snapshot is committed if an interrupted save left the primary missing, old, or already committed. A valid older primary is retained as a rollback backup when safe.
- **Data-loss prevention:** corrupt primary JSON is no longer rotated over a known-good backup. After restoring from backup, the first subsequent gameplay write keeps that recovery backup intact.
- Preserves future/unrecognized pending-save formats in read-only mode, just like protected primary and backup data; incompatible pending snapshots cannot silently downgrade the game.
- Invalid/truncated pending JSON does not roll back a healthy primary. A future-format backup remains protected while pending recovery completes.
