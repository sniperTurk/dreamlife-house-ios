# DreamLife House v2.33 (build 53)

- Crown Spark Weekly: earn a daily Crown + Lumen Canopy moment on 3 distinct days of the same game week; one claim per week grants 150 coins, 5 stars, +3 Fun and +3 Energy. Progress resets naturally on week transitions.
- Starlight Guardian milestone: after 7 lifetime Crown Spark moments, claim 160 coins, 5 stars, and the original wearable Comet Veil accessory.
- Comet Veil appears in Dress Up only after claiming the milestone; its equipped state persists across saves.
- House screen shows Crown Spark weekly and Guardian milestones. The expanding House content now scrolls vertically to keep lower rewards accessible on phones.
- Repaired 18 pre-existing regression tests that reloaded using the wrong UserDefaults save key (`test.save` instead of `save`).
- Added six XCTest regression cases for day/week boundaries, reward deduplication, accessory gating and save/reload.
- Version 2.33.0 / build 53.
- Fixed an additional legacy XCTest compile blocker: DEBUG-only internal fixture setters for four published state properties; release builds preserve read-only external access.
- Added explicit Apple Combine import and Linux model-only compatibility shim to enable model smoke checks.
