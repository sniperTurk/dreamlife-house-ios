# DreamLife House 2.8.0

- Added **Daily Memory Spark**, a lightweight daily keepsake quest.
- Interacting with two different displayed friendship keepsakes in the same in-game day unlocks a one-time 40 coin + 1 star reward.
- Repeated taps on the same keepsake do not inflate daily progress.
- Daily quest claim state is tied to the in-game day, so the next day starts a fresh memory challenge.
- House UI now shows daily keepsake progress and claim state whenever the player owns a keepsake.
- Added regression coverage for distinct-keepsake counting, one-claim-per-day protection, and next-day reset behavior.
