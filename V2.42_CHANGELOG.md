# DreamLife House v2.42.0 — build 62

## Gameplay and economy fixes
- **Side-slot decorations count:** placing a real owned decoration in either Main or Side slot now unlocks the House Adventure decoration reward. Previously the UI and model inspected only the legacy main-slot dictionary, leaving a valid side-slot player action uncredited.
- **Catalog purchase integrity:** `selectRoomItem` and `selectOutfit` reject caller-provided items with unknown IDs or noncanonical name/icon/price. Players cannot receive the Party outfit or Star Lamp for zero coins by passing a fabricated object.
- **Recipe reward integrity:** only the implemented Rainbow Cupcake can be recorded, with the fixed reward of 75 coins and one star. Caller-supplied inflated rewards or unknown recipes are ignored. First-completion-only behavior is preserved.
- No Barbie characters, names, images, audio or other protected assets were added.

## iPhone usability and regression coverage
- Rebuilt House Adventures into one vertical scroll region with stacked challenge cards, preserving reward IDs and VoiceOver state labels. The daily controls and all four claim buttons remain reachable on smaller screens.
- Added a DEBUG-only, isolated side-slot decoration UI fixture and a new XCUITest source case for claim, duplicate prevention and relaunch persistence.
- Added 7 model XCTest source methods, 33 executable Linux smoke assertions and 5 static UI wiring checks.

## Status
- Planned gameplay scope: **100%**, **+0 percentage points** versus v2.41.
- Real iOS build, XCTest, Simulator and physical iPhone/iPad tests remain pending macOS/Xcode. App Store release readiness is not verified.
