# DreamLife House v2.54.0 — build 74

## Parent recovery safety and accessible overview

- The parent recovery screen now summarizes **how many of the three save copies are present, how many distinct raw-byte versions exist, and how many are readable, damaged or require a newer app**. The summary is derived from the same captured inspection bytes as the individual preview rows, so the totals do not silently disagree with the reviewed candidates. VoiceOver can access the overview via `settings.recoverySummary`.
- Exporting a private recovery archive now requires a **separate confirmation** before opening the system Files exporter. The confirmation explains that the archive can include player names, progress and preferences and is **not encrypted**. This is a privacy warning, not proof of adult identity.
- The save bytes are rechecked **when the confirmation is accepted**, not when the initial Export button is tapped. If another session changes any of the three slots while the dialog is open, the export is rejected, the stale inspection is discarded and the user is asked to refresh and review the copies. No game saves are restored, merged, deleted or uploaded.
- Added four XCTest source tests, one XCUITest source test, 23 executable Linux Swift model assertions, and nine static UI wiring contracts.
- Replaced the slow serial smoke entry point with a parallel isolated Swift runner. All historical suites v2.33–v2.54, the archive verifier and static UI wiring checks run in a single command.
- All characters, visuals and gameplay remain original and independent of third-party franchises.
