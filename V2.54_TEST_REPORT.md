## Limitations

The parent confirmation is an extra deliberate action, **not** an adult authentication gate. A system Files picker can still share an unencrypted archive containing player details. The overview compares **exact raw bytes**, not which copy is correct; equivalent JSON with different byte ordering counts as different. UserDefaults multi-key reads remain best-effort and are not a cross-process transaction. The dialog's native appearance and VoiceOver behavior need actual iOS testing. No automatic save import or conflict resolution exists.
