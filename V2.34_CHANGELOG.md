# DreamLife House v2.34 (build 54)

## Critical playability repair
- Fixed a v2.29–v2.33 UI omission: **Radiant Chime** and **Lumen Canopy** had GameStore actions but no buttons in House. Their missing controls made Lightkeeper Weekly, Lightkeeper Streak, Crown Spark Weekly, and the Crown Spark/Comet Veil reward chain unreachable in ordinary gameplay. Both are now actionable in a horizontally scrolling **Living Room** decoration toolbar, with accessible control IDs and feedback.
- Extracted this toolbar into a small `@ViewBuilder` to limit additional SwiftUI type-checker complexity in the large House view.

## Original new content
- **Crown Spark Collection** tracks actual weekly Crown Spark *reward claims*, not merely daily progress, and displays four tiers: First Spark, Shimmer Keeper, Comet Collector, and Skyward Legend.
- After three claimed weeks, the player can claim the original **Comet Halo** decoration plus **110 coins and 4 stars** once. Comet Halo is interactive only in the Living Room (+2 Fun / +2 Energy per tap), with persistent unlock and visit count.
- Added an interactive **Comet Veil glow preview** in Dress Up. It respects the player's Reduced Motion preference.
- Reuses existing v2.33 persistence keys; no save schema migration needed.

## Verification
- Added six new XCTest regression methods (161 → 167), including historical claim counting, invalid/future week exclusion, one-time reward, save/reload, room gating, Chime → Canopy order, and Comet Veil/Crown separation.
- Linux Swift model smoke expanded to **58/58 assertions** (was 23/23 in v2.33).
- New House static wiring contract: **9/9** checks for missing controls, routing, and accessibility identifiers.
- `swiftc -parse` all Swift files: PASS; Linux model+XCTest source `swiftc -typecheck`: PASS (one expected same-module `@testable import` warning).
- Actual Xcode iOS build, iOS Simulator XCTest and physical iPhone/iPad checks still require macOS/Xcode.
