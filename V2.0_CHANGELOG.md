# DreamLife House 2.0 — Release Candidate

- Added explicit save schema version 3 for safe future migrations.
- Legacy saves without a schema marker migrate automatically and are rewritten in the current format.
- Future/incompatible save schemas are no longer rewritten by older builds; a compatible backup is recovered when available.
- Added regression coverage for legacy migration and downgrade-safe backup recovery.
- Version bumped to 2.0.0 (build 20).
