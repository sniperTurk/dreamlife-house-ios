# DreamLife House v2.7

- Displayed Friendship Keepsakes now render as interactive objects inside each room scene.
- Tapping a displayed keepsake creates a small friendship-memory interaction and grants +1 friendship XP to its associated original friend.
- Keepsake interaction counts persist through the existing save system and are available for future story/task hooks.
- Added room lookup for displayed keepsakes so moves remain deterministic.
- Added three regression tests for interaction gating, friendship reward/counting, and room-move lookup.
