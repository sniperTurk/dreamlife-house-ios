# DreamLife House v2.56.0 — build 76

## Build-blocking fixes (the UI layer had never been compiled)
- `PetView` called `TopBar(title:)`, but `TopBar` had no `title` parameter → compile error. `TopBar` now accepts an optional title.
- `HouseView` and `CharacterCreatorView` used `cond ? .pink.opacity(0.2) : .thinMaterial` (Color vs Material in one ternary) → compile error. Replaced with a shared `TileButtonStyle`.
- `HouseView` (≈6,000 characters on one line) and `FriendsView` (≈3,700) were single SwiftUI expressions that Xcode cannot type-check in reasonable time. Both are split into small sub-views.

## App Store blockers
- Added `Assets.xcassets` with a 1024×1024 opaque app icon (`AppIcon`), `AccentColor`, launch background colour and launch logo. The project had no icon, which App Store Connect rejects.
- Info.plist (via `project.yml`): all four iPad orientations (required for iPad multitasking validation), portrait on iPhone, `ITSAppUsesNonExemptEncryption = NO`, light appearance, launch screen colour/logo, explicit version keys.
- `project.yml`: `ASSETCATALOG_COMPILER_APPICON_NAME`, accent colour, automatic signing, `DEVELOPMENT_TEAM` placeholder, version 2.56.0 (76). Bundle ID is still `com.example…` and **must** be replaced.

## Gameplay / UX bugs fixed
- Late-game Living Room collectibles (Trophy, Aurora, Prism, Suncatcher, Terrarium, Lantern and Trophy decorations) were absolutely positioned on top of each other. They now sit on a scrollable "My Collection" shelf.
- Displayed keepsakes wrapped onto the same three positions (4th/5th overlapped 1st/2nd). They now sit on a wall shelf.
- The character did not follow the finger while dragging; it now moves live and is kept inside the room.
- "Confirm purchases" setting did nothing. Coin purchases of decorations and outfits now ask for confirmation when it is on.
- "Sound" and "Haptics" toggles did nothing. They now control system click sounds and haptic feedback.
- 8 tabs pushed Adventures and Settings into iPhone's "More" list. Reduced to 5 tabs: House, Me (look + wardrobe), Play (kitchen, pet, friends), Adventures, Settings.
- The day button read "Next Morning" while it was already morning; now "Go to Afternoon / Go to Evening / Sleep until Day N".
- Side decoration spot showed the starter sofa when empty; it now shows an empty "+" spot.
- Loaded saves now normalise character name / look IDs and the pet name (edited saves could carry values the UI cannot draw).

## Visual redesign
- New pastel theme (rounded type, plum text colour for contrast, cards, candy buttons, coin/star HUD pills, soft background).
- Original vector character drawn in SwiftUI that finally reflects hair style, hair colour, skin tone, outfit and accessory (previously a generic smiley icon).
- Five illustrated rooms (wall, floor pattern, window, furniture) with a visible drop zone for each room activity; pet and invited friend appear in the room.
- Original friend avatars, drawn cat/dog pet portrait, illustrated cupcake and step tracker in the kitchen, redesigned onboarding.
